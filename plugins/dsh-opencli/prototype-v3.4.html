对比 anweat/dsh-browser 0.1.10（我们到底差在哪）
anweat 有 vs 我们有：
Y 浏览器运行时：Playwright/Patchright + 通道 + headless + autoInstall
Y 自动化 4 档：read-only / standard / autonomous / unrestricted + 审批门
Y usagePolicy 限流：minDelay / maxConcurrency / burst / maxPagesPerRun / cooldown
Y 自动化资产：recipe + userscript（保存草稿 → 真实回放 → 手动激活 三步）
Y AuthProfile 限域登录：allowedDomains + storageStatePath
Y RulePack：域名匹配 + SHA-256 哈希 init script + 有界步骤
我们胜出的：
Y 170+ 站点适配器（anweat:0） — 核心护城河
Y 登录态自动复用你真实 Chrome（anweat 要 storageState JSON）
仍然差：
N 客户端设置面板做"运行时配置"（anweat 有完整 SettingsCard 嵌在 DSH 设置 → 插件）
N 自动化资产的"候选-草稿-激活"全流程 UI（anweat 整套 automation-assets-client.ts）
N 13 种 浏览器/资产 i18n 文案（中文界面我们没做）
N settings-namespace 注册（DSH 客户端 settings 命名空间机制我们没用）
