## 走查过程中的两个环境教训(记录防复发)

1. **dsh daemon 重启后 token 轮换**:web UI 必须 `http://127.0.0.1:3123/?token=<启动日志里的值>` 访问。
   裸 URL 会渲染 UI 壳但所有交互被门控(点击无响应、RPC 401)——GUI 走查"输入全失灵"的真相就是
   重启后用了裸 URL。token 每次重启都变,从 daemon 启动日志 `dsh web: http://...?token=...` 取。
2. **验证脚本自身会污染现场**:review 套件按 `site === 'site zhihu hot'` find 第一个任务,
   前一轮遗留的任务会让断言错配。套件/脚本跑完必须清理(schedules=0),重跑前查状态文件。

## 遗留(非 bug,环境项)

- **BrowserBridge 未连接**:opencli 桥要求 Chrome + OpenCLI 扩展,当前环境是 Edge。
  装好扩展后登录态真数据链路(真实采集/快照/报告)即可跑通,失败分类 `BROWSER_CONNECT` 的
  指引文案已验证正确指路。

  与本插件无关;GUI 自动化用自管 Edge + puppeteer 通道绕开。
